# ShiftSync

ShiftSync is a web-based staff scheduling platform for Coastal Eats, a fictional restaurant group operating across multiple locations and time zones.

The project focuses on real-world scheduling concerns such as staff availability, skills and location certifications, shift coverage and swaps, overtime warnings, fair shift distribution, realtime updates, and clear explanations when an assignment conflicts with a scheduling rule.

The application is being built with Next.js and TypeScript. More detailed setup, architecture, testing, and deployment documentation will be added as development progresses.
